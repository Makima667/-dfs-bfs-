# 课程设计报告：PathLab 路径搜索算法可视化系统

## 一、项目名称

PathLab 路径搜索算法可视化系统

## 二、项目背景

路径搜索算法是图论和人工智能中的重要内容，在地图导航、机器人路径规划、游戏寻路、物流路线规划等场景中都有广泛应用。传统学习过程中，算法往往只以代码和文字形式呈现，搜索过程不够直观，难以观察不同算法在同一地图上的运行差异。

本项目基于 JavaFX 实现了一个路径搜索算法可视化系统，通过网格地图、颜色变化和动画展示，让用户能够直观观察 BFS、DFS、Dijkstra 和 A* 算法的搜索过程、访问节点数量和最终路径，从而加深对路径搜索算法的理解。

## 三、需求分析

### 1. 功能需求

系统需要支持以下功能：

1. 显示二维网格地图。
2. 支持用户设置起点、终点和障碍物。
3. 支持用户选择不同搜索算法。
4. 支持动态展示算法搜索过程。
5. 支持显示最终路径。
6. 支持统计访问节点数、路径长度和计算耗时。
7. 支持清除痕迹、清空障碍、重置地图。
8. 支持随机障碍和迷宫地图生成。
9. 支持导出当前网格截图，方便报告展示。

### 2. 非功能需求

1. 界面操作简单直观。
2. 算法运行过程可视化明显。
3. 程序能够在 Windows 环境下直接运行。
4. 代码结构清晰，便于后续扩展更多算法。

## 五、系统设计

### 1. 总体结构

系统主要由三个部分组成：

1. **界面层**：负责显示网格、按钮、选择框、滑块和状态信息。
2. **控制层**：负责处理鼠标事件、按钮事件和动画播放。
3. **算法层**：负责实现 BFS、DFS、Dijkstra 和 A* 搜索逻辑。

项目主要文件如下：

```text
java/Main.java        程序入口
java/UI.fxml          JavaFX 界面布局
java/Controller.java  事件处理、算法实现、动画展示
```

### 2. 网格设计

系统使用二维数组表示地图：

```text
0：空白格子
1：障碍物
2：起点
3：终点
4：已访问节点
5：最终路径
```

不同数字在界面中会显示为不同颜色，方便观察算法过程。

### 3. 交互设计

用户可以通过鼠标直接编辑地图：

| 操作 | 功能 |
|---|---|
| 左键 | 绘制或取消障碍物 |
| 右键 | 擦除格子 |
| Shift + 左键 | 设置起点 |
| Ctrl + 左键 | 设置终点 |

## 六、核心算法设计

### 1. BFS 广度优先搜索

BFS 使用队列维护待访问节点。它会按照层次逐步向外扩展，在无权图中可以找到从起点到终点的最短路径。

基本步骤：

```text
1. 将起点加入队列。
2. 每次取出队首节点。
3. 遍历当前节点的上下左右邻居。
4. 如果邻居没有访问过且不是障碍物，则加入队列。
5. 使用 parent 数组记录路径来源。
6. 找到终点后，根据 parent 反向恢复路径。
```

### 2. DFS 深度优先搜索

DFS 使用栈结构，优先沿着一个方向不断深入。它可以展示深度优先搜索的特点，但不保证找到最短路径。

### 3. Dijkstra 算法

Dijkstra 使用优先队列，每次选取当前距离最小的节点进行扩展。在边权非负的图中，Dijkstra 可以求出最短路径。

本项目中直线移动代价为 10，斜向移动代价为 14，用来近似二维网格中的距离。

### 4. A* 算法

A* 算法在 Dijkstra 的基础上加入启发式函数，优先搜索更可能接近终点的节点。

本项目中：

- 不允许斜向移动时，使用曼哈顿距离。
- 允许斜向移动时，使用八方向距离估计。

A* 通常比 Dijkstra 访问更少节点，搜索效率更高。

## 七、功能实现说明

### 1. 搜索过程动画

算法运行后不会直接一次性显示结果，而是先保存访问节点顺序和最终路径，再使用 JavaFX 的 `Timeline` 按时间间隔逐个绘制节点颜色，从而形成动态效果。

### 2. 迷宫生成

系统加入了迷宫生成功能。迷宫生成使用随机深度优先思想：

```text
1. 先将所有格子设为墙。
2. 从一个奇数坐标格子开始。
3. 随机选择未访问的相邻格子。
4. 打通当前格子和目标格子之间的墙。
5. 不断回溯直到所有可达格子都被处理。
```

生成迷宫后，可以选择 BFS、Dijkstra 或 A* 观察不同算法的寻路效果。

### 3. 截图导出

为了方便课程报告和答辩展示，系统支持将当前网格导出为 PNG 图片，保存到项目根目录的 `screenshots` 文件夹中。

## 九、项目特色

1. 支持多种经典路径搜索算法。
2. 支持可交互编辑地图。
3. 使用动画展示搜索过程，直观清晰。
4. 支持迷宫生成，展示效果更强。
5. 支持截图导出，便于课程报告和答辩。
6. 代码集中，运行方式简单，适合教学演示。

## 十、项目不足与改进方向

当前项目仍有一些可以继续优化的地方：

1. 可以将不同算法拆分成独立类，提高代码模块化程度。
2. 可以增加权重格子，进一步体现 Dijkstra 和 A* 的优势。
3. 可以增加地图保存和读取功能。
4. 可以增加更多迷宫生成算法。
5. 可以加入多智能体路径规划的完整可视化。

## 十一、总结

本项目完成了一个基于 JavaFX 的路径搜索算法可视化系统，实现了网格编辑、算法选择、搜索动画、路径显示、统计信息、迷宫生成和截图导出等功能。通过本项目，可以更直观地理解 BFS、DFS、Dijkstra 和 A* 等算法的搜索过程和应用场景，也提高了 JavaFX 图形界面开发与算法综合实践能力。
