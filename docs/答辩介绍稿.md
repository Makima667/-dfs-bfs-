# PathLab 答辩介绍稿

各位老师好，我的课程设计题目是 **PathLab 路径搜索算法可视化系统**。

这个项目主要是为了把路径搜索算法的执行过程用图形界面的方式展示出来。传统学习 BFS、DFS、Dijkstra 和 A* 算法时，我们通常只能看到代码和最终答案，不太容易观察算法是如何一步一步搜索的。因此我使用 JavaFX 做了一个可交互的网格地图，让用户可以自己设置起点、终点和障碍物，然后选择不同算法运行。

项目主要功能包括：

1. 支持在 30 × 25 的网格地图中绘制障碍物。
2. 支持设置起点和终点。
3. 支持 BFS、DFS、Dijkstra 和 A* 四种算法。
4. 支持动态显示搜索过程和最终路径。
5. 支持统计访问节点数、路径长度和计算耗时。
6. 支持随机障碍、迷宫生成和截图导出。

在实现方面，我使用二维数组保存地图状态，不同数字代表不同类型的格子，例如空白、障碍、起点、终点、已访问节点和最终路径。算法运行时，会先保存访问顺序和最终路径，然后通过 JavaFX 的 Timeline 实现动画播放，让搜索过程一格一格显示出来。

四种算法中，BFS 适合无权最短路，DFS 可以展示深度优先的搜索特点，但不保证最短路径。Dijkstra 适合带权最短路，A* 在 Dijkstra 的基础上加入启发式函数，因此通常访问节点更少，搜索效率更高。

本项目的亮点是交互性比较强，用户可以自由绘制地图，并且能够直观看到不同算法在同一地图上的搜索差异。同时，项目也加入了迷宫生成和截图导出功能，便于演示和报告展示。

项目不足之处是目前算法代码主要集中在 Controller 中，后续可以进一步拆分成独立算法类；另外也可以增加权重格子、地图保存读取以及多智能体路径规划可视化。

以上就是我的项目介绍，谢谢老师。
