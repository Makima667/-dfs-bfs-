# 打包说明

项目已经提供三个脚本：

```text
run_javafx.bat       编译并运行项目
build_jar.bat        打包成 PathLab.jar
package_app.bat      使用 jpackage 打包成应用文件夹
```

## 一、打包 JAR

双击：

```text
build_jar.bat
```

成功后会生成：

```text
dist/PathLab.jar
```

注意：由于 JavaFX 是外部 SDK，直接双击 JAR 通常不能运行，仍然建议用脚本启动。

## 二、打包应用文件夹

双击：

```text
package_app.bat
```

成功后会生成：

```text
dist/app/PathLab/
```

里面会包含启动程序。这个方式依赖 JDK 自带的 `jpackage` 工具。如果你的 JDK 没有 jpackage，需要安装 JDK 17 或更高版本。

## 三、最稳妥的提交方式

如果只是课程设计提交，推荐直接提交整个项目文件夹，并说明运行方式：

```text
双击 run_javafx.bat 运行
```

这样最不容易因为 JavaFX 路径或 JDK 环境问题出错。
