# 截图清单

建议至少准备下面 6 张截图，用于课程设计报告或答辩 PPT。

## 1. 主界面截图

打开程序后，不做任何操作，截一张主界面。

建议命名：

```text
01_主界面.png
```

## 2. 手动画障碍截图

用鼠标画一些障碍物，再设置起点和终点。

建议命名：

```text
02_手动画障碍.png
```

## 3. BFS 搜索过程截图

选择 BFS，运行到蓝色访问节点已经明显出现时导出截图。

建议命名：

```text
03_BFS搜索过程.png
```

## 4. A* 最终路径截图

选择 A*，运行结束后导出截图，展示黄色最终路径。

建议命名：

```text
04_AStar最终路径.png
```

## 5. 迷宫生成截图

点击“生成迷宫”，导出一张迷宫地图。

建议命名：

```text
05_迷宫地图.png
```

## 6. 迷宫寻路结果截图

在迷宫地图上运行 BFS 或 A*，运行结束后导出截图。

建议命名：

```text
06_迷宫寻路结果.png
```

## 截图导出方法

程序右侧有“导出截图”按钮。点击后，截图会自动保存到项目根目录的：

```text
screenshots/
```

如果要放到 Word 报告中，可以直接插入这些 PNG 图片。
